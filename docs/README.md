## English

DD-MB (Dopravní deník – Moduly Brno) is a web application for model railway dispatch operation. This page is the central index for all available documentation. Pick a topic below to get started.

### Getting Started

- **[Installation Guide](./INSTALL.md)** — How to install and run the DD-MB server and requirements needed to get it working.
- **[Initial Setup Guide](./INITIAL_SETUP.md)** — First steps after installation: creating stations, users, and preparing the layout for its first session.

### Using the Application

- **[Dispatcher](./DISPATCHER.md)** — The main dispatcher view used to operate trains: blocks, incoming/outgoing offers, pass-through trains, extra trains, train notes, graphical timetables, and more.
- **[Simplified Driver View](./SIMPLIFIED.md)** — A streamlined view for simplified end stations, designed for drivers: confirming arrivals, offering/retracting trains, ringing adjacent stations, and more.
- **[Admin Panel](./ADMIN.md)** — Administration of stations, timetables, and other server-wide settings.
- **[Rosters](./ROSTERS.md)** — Assigning drivers to circulations, preparing the next model day in advance, and tracking driver/roster statistics.

### Languages

DD-MB (Dopravní deník – Moduly Brno) je webová aplikace pro výpravu modelové železnice. Tato stránka je centrálním rozcestníkem veškeré dokumentace. Vyberte si téma níže.

### Začínáme

## Deutsch

DD-MB (Dopravní deník – Moduly Brno) ist eine Webanwendung für den Fahrdienstbetrieb einer Modelleisenbahn. Diese Seite ist der zentrale Index für die gesamte Dokumentation. Wählen Sie unten ein Thema aus.

### Erste Schritte

- **[Installationsanleitung](./INSTALL.md)** — Wie man den DD-MB-Server installiert und startet, sowie die dafür benötigten Voraussetzungen.
- **[Ersteinrichtungsanleitung](./INITIAL_SETUP.md)** — Erste Schritte nach der Installation: Anlegen von Stationen, Benutzern und Vorbereitung der Anlage für den ersten Betrieb.

### Verwendung der Anwendung

- **[Fahrdienstleiter](./DISPATCHER.md)** — Die Hauptansicht des Fahrdienstleiters zur Zugbedienung: Blöcke, ankommende/abgehende Angebote, Durchfahrende Züge, Sonderzüge, Zughinweise, grafische Fahrpläne und mehr.
- **[Vereinfachte Triebfahrzeugführer-Ansicht](./SIMPLIFIED.md)** — Eine vereinfachte Ansicht für Endstationen, für Triebfahrzeugführer: Bestätigen der Ankunft, Anbieten/Zurückziehen eines Zuges, Anrufen einer Nachbarstation und mehr.
- **[Admin-Bereich](./ADMIN.md)** — Verwaltung von Stationen, Fahrplänen und weiteren serverweiten Einstellungen.
- **[Turnusse](./ROSTERS.md)** — Zuweisung von Triebfahrzeugführern zu Umläufen, Vorbereitung des nächsten Modelltages im Voraus und Verfolgung von Fahrer- und Turnusstatistiken.

## Magyar

A DD-MB (Dopravní deník – Moduly Brno) egy webalkalmazás modellvasúti forgalomirányítási üzemeltetéshez. Ez az oldal az összes elérhető dokumentáció központi tartalomjegyzéke. Válasszon témát az alábbiakból.

### Kezdő lépések

- **[Telepítési útmutató](./INSTALL.md)** — Hogyan telepítse és indítsa el a DD-MB szervert, valamint az ehhez szükséges követelmények.
- **[Kezdeti beállítási útmutató](./INITIAL_SETUP.md)** — Első lépések a telepítés után: állomások, felhasználók létrehozása és az elrendezés előkészítése az első üzemeltetésre.

### Az alkalmazás használata

- **[Forgalomirányító](./DISPATCHER.md)** — A forgalomirányító fő nézete a vonatok kezeléséhez: blokkok, érkező/induló ajánlatok, áthaladó vonatok, rendkívüli vonatok, vonatmegjegyzések, grafikus menetrendek és további funkciók.
- **[Egyszerűsített mozdonyvezetői nézet](./SIMPLIFIED.md)** — Egyszerűsített nézet végállomásokhoz, mozdonyvezetők számára: érkezés megerősítése, vonat felajánlása/visszavonása, szomszéd állomás csengetése és további funkciók.
- **[Admin panel](./ADMIN.md)** — Állomások, menetrendek és egyéb szerverszintű beállítások kezelése.
- **[Turnusok](./ROSTERS.md)** — Mozdonyvezetők hozzárendelése körforgásokhoz, a következő modellnap előzetes előkészítése, valamint a mozdonyvezetői és turnusstatisztikák nyomon követése.
